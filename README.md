# RDR2Weather

Unreal Engine 5.9 project — RDR2 weather system.

## MCP (Model Context Protocol) — Claude controls Unreal Editor

This project enables UE's built-in **Unreal MCP** plugin, which exposes the editor as an MCP
server over HTTP on `http://localhost:8000/mcp`.

### How it works

1. UE 5.9 ships the `ModelContextProtocol` plugin (Friendly name "Unreal MCP"). It is enabled in
   `RDR2Weather.uproject` and auto-starts on editor launch via
   `Config/DefaultEditorPerProjectUserSettings.ini` (`bAutoStartServer=True`, port 8000, path `/mcp`).
2. Claude Code is configured as an MCP client via `.mcp.json` at the project root, pointing at
   `http://localhost:8000/mcp`.
3. When the editor is running, Claude can call MCP tools to inspect and drive the editor
   (list/set actors, run Python, take screenshots, manage content, etc.).

### Using it

1. Open `RDR2Weather.uproject` in Unreal Editor 5.9 (the registered engine at `E:/EpicGames/UE_5.9`).
   The MCP server starts automatically.
2. From this folder, start Claude Code — it reads `.mcp.json` and connects to the running editor.
3. Verify the connection is live (the `unreal-mcp` server appears and its tools are available).

### Notes

- The MCP server only listens on localhost; it is not exposed to the network.
- If you change the port or path in Editor Preferences → Plugins → Model Context Protocol, update
  `.mcp.json` to match and reconnect Claude Code.
- `Binaries/`, `Intermediate/`, `Saved/`, `DerivedDataCache/`, `.vs/`, and `*.sln` are git-ignored —
  they are regenerated by the engine and Visual Studio.
